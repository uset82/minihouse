# D001 · Symmetric overhanging beam — moments and midspan deflection

Status: **verified** (2026-11-16). Script: [verify_beam.py](verify_beam.py). Gate D1 passed.

## Statement

A beam of total length L carries a uniform load q over its full length. It is supported symmetrically at x = a and x = L − a, measured from the left free end. Find the moment at the support, the moment at midspan, and the midspan deflection.

## Assumptions

- Euler–Bernoulli: EI v″ = M, shear deformation neglected.
- Prismatic section, constant EI.
- Small deflections, linear elastic.
- Load q acts over 0 ≤ x ≤ L including the overhangs.
- Origin x = 0 at the left free end; v positive UP.

## Derivation

Total load qL; by symmetry each reaction R = qL/2.

For a section in the central span (a ≤ x ≤ L − a), taking the left segment:

M(x) = R(x − a) − q x²/2

At the support x = a: M_A = −q a²/2 (hogging from the overhang load).

At midspan x = L/2: M_mid = qL(L − 4a)/8.

Integrate EI v″ = M twice over the central span, then apply v(a) = 0 (support) and v′(L/2) = 0 (symmetry). SymPy gives (positive-up convention):

delta_mid = q (−L + 2a)² (−5L² + 20La + 4a²) / (384 EI)

The report quotes the downward magnitude:

|delta| = (q/EI) [ 5(L − 2a)⁴/384 − a²(L − 2a)²/16 ]

The two expressions are exact negatives: symbolic sum = 0.

## Unit check

q/EI has units (N/m)/(N·m²) = 1/m³. Bracket has units m⁴. Product = m. Correct for a deflection.
q a² has units (N/m)(m²) = N·m. Correct for a moment.

## Numerical check (report's hypothetical case)

L = 6 m, q = 2452.5 N/m, EI = 1.68 × 10⁶ N·m²

| a (m) | M_A (kNm) | M_mid (kNm) | |delta_mid| (mm) |
|---|---|---|---|
| 0.0 | 0.000 | 11.036 | 24.634 |
| 1.2 | −1.766 | 2.207 | 1.490 |

All three values reproduce the report exactly.

## Where it is valid / where it fails

Valid: one prismatic ideal beam, symmetric supports, uniform load, linear elastic, no torsion, no joint flexibility.

Fails for the real module (the report's own warning): rectangular chassis torsion, cross members, joint flexibility, local tube deformation at lifting ears, point loads from bathroom/kitchen/tanks/batteries, wall interaction, large openings, floor diaphragm stiffness, mass asymmetry, trailer deformation, out-of-plane sling action. **Do not** read 1.2 m as an optimal support position or 24.6 / 1.49 mm as module deflections.
