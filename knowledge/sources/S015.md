# S015 · The Turing Way — reproducible research

- **Title:** The Turing Way: A Handbook for Reproducible, Ethical and Collaborative Data Science
- **URL:** https://book.the-turing-way.org/reproducible-research/overview.html and /reproducible-research/compendia.html
- **Publisher:** The Turing Way Community
- **Access:** free, open access (verified 2026-11-16); illustrations CC-BY 4.0

## Key claims

- Results are strengthened when replicated/confirmed by independent researchers. Transparency — documenting and sharing data and processes — lets others reproduce or build on results.
- A **research compendium** = collection of all digital parts of a project (data, code, texts, protocols, metadata) assembled so reproducing all results is straightforward.
- Three principles: conventional folder structure; **data, methods and output clearly separated**; computational environment specified.
- File-category distinction: **read-only** (raw data, metadata), **human-generated** (code, paper, documentation), **project-generated** (clean data, figures, output).
- Basic compendium = folders + README + environment description. Executable compendium adds CITATION, Dockerfile, Makefile, LICENSE.
- Publishing options: GitHub/GitLab, Zenodo/OSF, or paper supplementary material.

## Relevance to MiniHouse

The `knowledge/` structure already follows these principles: `sources/` (read-only primary material and local PDFs), `derivations/` (human-generated reproducible scripts + cards), `comparisons/` (project-generated reports), plus `INDEX.md` as landing page. Verification scripts (`verify_beam.py`, `verify_rigging.py`, `scripts/masas_cg.py`, `scripts/r0_parametric.py`) make parts of the work executable. Remaining gap: no explicit `LICENSE`, `CITATION` or environment file — add if the package is published externally.

## Limits

Generic research-method guidance; not engineering-specific and not a substitute for ASME V&V or design-science methodology (still to acquire).
