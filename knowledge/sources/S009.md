# S009 · Statens vegvesen — special transport dispensation (VegSak)

- **Title:** Søk om dispensasjon for spesialtransport
- **URL:** https://www.vegvesen.no/kjoretoy/yrkestransport/veglister-og-dispensasjoner/sok-om-dispensasjon/dispensasjon-for-spesialtransport-vegsak-elektronisk-soknad
- **Publisher:** Statens vegvesen (Norwegian Public Roads Administration)
- **Access:** free, official (verified 2026-11-16)

## Key claims (verbatim where relevant)

- "For å søke om dispensasjon for spesialtransport må du bruke tjenesten VegSak. Du må søke i god tid før transporten starter." — dispensation applications use the VegSak service and must be submitted well in advance.
- Dispensation is granted under **forskrift om bruk av kjøretøy § 5, Vekter og dimensjoner** (weights and dimensions).
- Permitted weights/dimensions are set in **forskrift om bruk av kjøretøy kap. 5** (Lovdata: https://lovdata.no/dokument/SF/forskrift/1990-01-25-92).
- Bruksklasse (use class), allowed combination length and **veggruppe** for each road section are found in the **riksvegliste for spesialtransport**, county/municipal road lists, and in **Vegkart** (zoom in, select "Bruksklasse" top-right, click the road section).
- New users must register for VegSak; user documentation PDF available.
